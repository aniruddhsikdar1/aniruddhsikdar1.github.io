Project Deliverables Data Generation Using Generative Modeling for Side-Scan Imagery.
  • Addressed the challenge of limited real-world side-scan sonar (SSS) data for deep learning–based underwater object detection and segmentation.
  • Proposed a synthetic side-scan sonar dataset generated via diffusion-based generative modeling.
  • Demonstrates significant improvements in downstream tasks, including object detection and semantic segmentation.
Course Project Unsupervised Domain Adaptation
  • Addressed performance degradation caused by domain shifts by enabling learning on unlabeled target data through unsupervised domain adaptation.
  • Implemented a Mean Teacher–based self-ensembling framework to improve robustness and cross-domain generalization.
  • Performed cross-domain adaptation experiments between MNIST and SVHN using labeled source data and unlabeled target data.
  • Incorporated confidence thresholding and extensive data augmentation to stabilize training and enhance learning.
  • Achieved near-supervised performance, demonstrating the effectiveness of self-ensembling strategies for domain transfer.
Course Project One-Shot Object Localization for Robotic Manipulation
  • Addressed the challenge of localizing novel objects from a single visual cue without prior object-specific training.
  • Enabled robotic pick-and-place in unstructured environments through vision-based one-shot localization.
  • Implemented a Siamese CNN with shared weights to learn similarity between cue and scene images.
  • Designed a spatial attention mechanism to extract object-specific features from the cue image.
  • Generated similarity score maps and applied SoftArgMax to accurately predict object coordinates.
  • Integrated vision-based localization with inverse kinematics control for robotic picking in both simulation and real hardware.
