Developing methods that enable deep learning models to generalize to unseen target domains by learning domain-invariant representations from source data alone.

{% include figure.liquid loading="eager" path="assets/img/publication_preview/arch.png" title="MRFP Architecture" class="img-fluid rounded z-depth-1" %}

**Key contributions:**
- **MRFP** (CVPR 2024) — Multi-resolution feature perturbation for Sim-to-Real generalizable semantic segmentation.
- **Picazo** (CVPR 2025) — Pixel-aligned contrastive learning for zero-shot domain adaptation.
- **DGMeta** (ETAAV 2025) — Metacognitive Mask R-CNN for domain generalization under environmental uncertainties.
- **Syn2Real** (IEEE GRSL 2025) — Diffusion-based synthetic data generation for underwater mine detection with side-scan sonar.
