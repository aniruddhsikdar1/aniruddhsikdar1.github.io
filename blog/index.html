CLIP-CAM: Explainable Image–Text Alignment for CLIP Models GitHub PyPI

CLIP-CAM is an open-source Python package for generating Grad-CAM–style visual explanations in Vision Transformer (ViT)–based CLIP models, enabling deeper insight into how specific image regions drive image–text similarity scores.

  • Modular and extensible framework for visualizing cross-modal attention in CLIP, built around Grad-CAM–based heatmap generation.
  • Customised for CLIP's dual-encoder architecture, revealing which image patches contribute most to a given text query.
  • Lightweight API — works with standard HuggingFace and OpenAI CLIP checkpoints with minimal setup.

Dataset Contributions

IndraEye: The first multi-view drone-based RGB-IR dataset from the Indian subcontinent, built to support robust and accurate real-world vision systems.
  • Benchmarked for object detection and semantic segmentation tasks.
  • Captures diverse conditions including multiple viewpoints, altitudes, and backgrounds.
  • Includes variations across times of day to evaluate robustness under changing illumination.
  • Published · CVPR-W PBVS 2025

Side Scan Sonar Dataset: A proposed dataset to enable robust underwater perception using side-scan sonar imagery.
  • Addresses the challenge of limited real-world side-scan sonar (SSS) data for deep learning–based underwater object detection and segmentation.
  • Highlights data scarcity as a key cause of overfitting and poor generalization to unseen underwater environments.
  • Proposes a synthetic side-scan sonar dataset generated via diffusion-based modeling.
  • Demonstrates significant improvements in downstream tasks, including object detection and semantic segmentation.
  • Published · IEEE OCEANS · IEEE Remote Sensing Letters

Simulated IR dataset: Infrared imagery dataset supporting thermal perception, multi-modal learning, and sim-to-real robotics in low-light environments.
  • Introduces SSL-RGB2IR, a self-supervised image-to-image translation framework for generating high-quality infrared (IR) data.
  • Deep learning models consistently achieve superior performance when trained on IR images synthesized using SSL-RGB2IR compared to other translation methods.
  • It demonstrates consistent performance gains in semantic segmentation and object detection, particularly in sim-to-real scenarios.
  • Published · IROS 2024
